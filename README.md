# PersonalWeb (React)

This project now runs as a React web app using Vite.

## Run locally

1. Install dependencies:

	npm install

2. Start the React dev server:

	npm run dev

3. Open the local URL shown in the terminal (usually http://localhost:5173).

## Build for production

npm run build

## Preview production build

npm run preview

## Project structure

- `index.html` - App shell that contains the `#root` element.
- `src/main.jsx` - React entry point that mounts the app.
- `src/App.jsx` - Main page component and UI layout.
- `Views/` and `app.js` - Existing Express/static files kept for reference.
